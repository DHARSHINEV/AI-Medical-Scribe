System Architecture & Security: MediScribe utilizes an extensible AI Provider architecture. In this client-side prototype, DemoProvider runs deterministic local extraction logic without external network dependencies. For real-world production, external LLM calls must be proxied via a secure HIPAA-compliant backend service to prevent client-side API key exposure.
